# Edmonton Off-Site (MIA) Plan Requirements

Off-site = Lane Design (MIA). 항상 있는 것은 아님.

---

## 1. COVER SHEET (C001-001-COVER)

- [ ] Name of Subdivision
- [ ] Stage of Development
- [ ] Approval Number, Development and Consultant name
- [ ] Key Plan

## 2. Topography Plan (C004-001-TOPO)

- [ ] Original Contour — Contour Interval **0.5m**
- [ ] Legal Plan Information
- [ ] Project Limit
- [ ] Survey 누락 데이터 — Roof, Driveway, Pavement linework 보완

## 3. Overall Storm, Sanitary and Watermain (C005-001-UTILITIES)

- [ ] Sanitary, Water, Storm 위치 치수 (가로/세로)
- [ ] 가스/전력 — 별도 플랜이지만 location dimension 포함

## 4. Road and Sidewalk Plan (C006-001-ROAD)

- [ ] Walkway, Road widths and Alignments
- [ ] Catch basin, MH 위치 (dimension 불필요)
- [ ] Ex and Prop Road, Alley, Shared Use Path, Sidewalk 라벨
- [ ] Project Limit
- [ ] Bus pad

## 5. Grading Plan (C007-001-GRADING)

- [ ] Finish Lot Corner Elevation
- [ ] Direction of Flow
- [ ] Original Contour
- [ ] Berm, Prop Curb and Gutter Alignment

## 6. Profile Plan (C100-001-Lane/Street)

- [ ] Legal Plan Information
- [ ] Street name
- [ ] Ex and Prop Road, Alley, Shared Use Path, Sidewalk 라벨
- [ ] 인접 Street, Walk, Alley, Ditch data 라벨
- [ ] Prop Lip of Gutter profile
- [ ] Existing and Prop CL elevation
- [ ] Easement

- [ ] (해당 시 SWM 시설 도면)

## 8. ESC Plan (C015-001-ESC)

- [ ] ESC General Notes 포함 (erosion & sediment control, spill control, silt fence notes)
- [ ] 도면에 ESC 시설 위치 표시

## 9. Detail (C200-001-DETAIL)

- [ ] 해당 디테일 도면 포함
