## 3. Site Servicing Plan (C003)

- [ ] Property line and dimensions
- [ ] Street, Avenue, Lane 라벨
- [ ] 모든 Easement, Utility ROW 표시
- [ ] Sanitary, Water, Storm 위치 치수 — 가장 가까운 Property Line으로부터 가로/세로
  - [ ] 미사용 서비스: "Not in use, to be abandoned" 표기
  - [ ] 서비스 라벨 형식: `XX.XXm - 200mm EX STM PVC SERV @ 1.00% (BY OTHER)`
  - [ ] MH 라벨 형식: `STMH1 (BY OTHERS) / RIM xxx.xx / INV @ BLD = xxx / INV @ MH = xxx / INV @ PLUG = xxx`
- [ ] Property Line에서의 서비스 Invert 표시
- [ ] **Sampling Manhole**: Sanitary **2%**, Storm **1%**
- [ ] 가스/전력 Location Dimension
- [ ] 전신주, 나무, 가로등, Pedestals, 옹벽, 울타리, 표지판, 신호등
- [ ] 지표면 상태: Pavement, Gravel, Landscape + Parking Area, Loading Zone
- [ ] **45m Hydrant Coverage** 확인
- [ ] Area Drain Spec Sheet 포함
- [ ] **TVS (Tapping Valve Sleeve)**:
  - 건물↔PL < 3m → WA-005-010
  - 건물↔PL = 0m (완전 접함) → WA-005-009
  - 건물↔PL > 3m → 디테일 불필요
- [ ] **Note**: "The owner/developer must conform to the requirements of the City of Edmonton Erosion and Sedimentation Control Guidelines and Field Manual"

## 4. Grading Plan (C004)

- [ ] Existing & Finish Lot Corner Elevation
- [ ] Property lines and dimensions
- [ ] Street, Avenue, Lane 라벨
- [ ] 모든 Easement, Utility ROW 표시
- [ ] Surface water → 이웃 property로 유입 금지
- [ ] Direction of Flow: **Hard surface 0.75%**, **Landscape & Gravel 1.5%**
- [ ] Original Contour
- [ ] Berm, Prop Curb and Gutter Alignment
- [ ] Prop Retaining Wall, Swale — Elevation and Slope 표시
- [ ] Area Drain & Manhole — Location & Rim Elevation
- [ ] 측량 기준점 (ASCM) 표시
- [ ] **Overflow point** 위치 및 높이 표시
- [ ] **최저 건물 개구부(Lowest building opening) ≥ Overflow + 150mm**
- [ ] **건물 인접 첫 2.0m**: 잔디 **10%**, 단단한 표면 **0.75%**
- [ ] 지표면 상태: Pavement, Gravel, Landscape + Parking Area, Loading Zone
- [ ] **Note**: "Private storm drainage system demonstrating compliance with the Drainage Bylaw 18100"
- [ ] **Note**: "The owner/developer must conform to the requirements of the City of Edmonton Erosion and Sedimentation Control Guidelines and Field Manual"

## 5. Stormwater Management Plan (C005)

- [ ] Property lines and dimensions
- [ ] Street, Avenue, Lane 라벨
- [ ] Area Drain Detail
- [ ] 우수 관리 제어 및 현장 저장 요구사항 준수 입증
- [ ] 유틸리티 라인, 맨홀, 집수정 — Invert + Rim Elevation
- [ ] 유량 제한 장치/Orifice plate 크기 및 위치
- [ ] 최대 저류(Ponding) 구역 외곽선 — 상단 높이 + 월류 위치
- [ ] 유역 경계(Basin boundaries) 외곽선 (해당 시)
- [ ] 지붕 배수구(Roof drains) 위치 — 유형, 사양 (제조사, 모델, 최대 유량)
- [ ] **Overflow point** 위치 및 높이
- [ ] **SWM 계산서 (도면에 표시)**:
  - [ ] 전체 개발 면적 (ha)
  - [ ] 평균 유출 계수
  - [ ] 필요 현장 저류 용량 (m³)
  - [ ] 달성 저류 용량 (m³) + 계산 근거
  - [ ] 최대 허용 유출속도 (m³/s)
  - [ ] 유량 제한/Orifice 크기 (mm) + 데이터 시트
  - **Orifice 최소 크기: 50mm** (round, sharp-edged)
- [ ] Orifice 크기 Calculation
- [ ] **Note**: ESC Guidelines 준수
