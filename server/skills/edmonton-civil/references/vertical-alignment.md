# Vertical Alignment Standards — City of Edmonton

## Vertical Curve K Values

The K value is the horizontal distance (in metres) required for a 1% change in grade.

**Minimum K value: 5**

| Curve Type | Minimum K | Design Speed | Notes |
|------------|-----------|-------------|-------|
| Crest (sag) | 5 | TBD | Minimum for residential lanes |
| Sag | 5 | TBD | Minimum for residential lanes |

### K Value Formula

```
K = L / A
```

Where:
- **K** = rate of vertical curvature
- **L** = length of vertical curve (metres)
- **A** = algebraic difference in grades (%)

### Example
- Grade 1: +2.0%
- Grade 2: -1.0%
- A = |2.0 - (-1.0)| = 3.0%
- Minimum L = K × A = 5 × 3.0 = 15 metres
