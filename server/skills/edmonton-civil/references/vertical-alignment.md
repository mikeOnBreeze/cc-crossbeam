# Vertical Alignment Standards — City of Edmonton

## Vertical Curve K Values

The K value is the horizontal distance (in metres) required for a 1% change in grade.

**Minimum K value: 5**

| Curve Type | Minimum K | Design Speed | Notes |
|------------|-----------|-------------|-------|
| Crest | 5 | **30 km/h** | Minimum for residential lanes |
| Sag | 5 | **30 km/h** | Minimum for residential lanes |

### K Value Formula

```
K = L / A
```

Where:
- **K** = rate of vertical curvature
- **L** = length of vertical curve (metres)
- **A** = algebraic difference in grades (%)

### Example
- Grade 1: +2.0%
- Grade 2: -1.0%
- A = |2.0 - (-1.0)| = 3.0%
- Minimum L = K × A = 5 × 3.0 = 15 metres

## Vertical Curves — Minimum Required Slope

Vertical curves require the following minimum slopes by road classification:

| Road Classification | Minimum Slope (%) |
|--------------------|-------------------|
| Arterial | 1.0 |
| Collector | 1.5 |
| Local | 1.5 |
| Alleys | 2.0 |

## Minimum Longitudinal Grade

| Facility Type | Minimum Grade (%) |
|---------------|-------------------|
| Walkway | 0.6 |
| New Alley | 0.7 |

## Maximum Grades

| Road Classification | Maximum Grade (%) |
|--------------------|-------------------|
| Arterial | **6%** |
| Collector | **8%** |
| Local | **10%** |
| Alleys | **10%** |

## Stopping Sight Distance (SSD)

| Design Speed (km/h) | Minimum SSD (m) |
|---------------------|-----------------|
| 30 | **30** |
| 40 | **45** |
| 50 | **65** |
| 60 | **85** |
| 70 | **110** |
| 80 | **140** |

- Based on TAC Geometric Design Guide for Canadian Roads
- SSD = perception-reaction distance + braking distance
- Measured from driver eye height (1.05 m) to object height (0.38 m)

## Grade Breaks

A vertical curve is required when the algebraic difference in grades exceeds **1%**.

| Grade Change (A) | Requirement |
|-------------------|------------|
| A ≤ 1% | Grade break allowed (no vertical curve needed) |
| A > 1% | Vertical curve required with minimum K = 5 |

**Example**: If Grade 1 = +2.0% and Grade 2 = +0.5%, then A = 1.5% → vertical curve required.
